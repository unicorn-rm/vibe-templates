### Added
- `01-swiss-saas` — Gridline, Swiss-grid SaaS landing (Next.js 16, Tailwind CSS 4).
- `02-terminal-portfolio` — retro CRT developer portfolio with a working command line (vanilla JS).
- `05-neon-festival` — Neon Bloom, risograph-poster music festival with a two-ink halftone audio visualizer (React, Vite, Motion).
- `14-fine-dining` — Ombre, dark-luxury restaurant with a pinned tasting menu (GSAP).
- `03-coffee-editorial` — Paper Moon, editorial coffee roaster with drawn menu and brew timer (Astro 7).
- `04-brutalist-architecture` — MASSA, brutalist studio with horizontal scroll and isometric models (GSAP).
- `06-cyber-security` — Bastion, security consultancy styled as a declassified file with redactions and a stamped request form (Next.js 16, Tailwind 4).
- `07-photographer` — Ines Varo, minimal photo portfolio with masonry and lightbox (SvelteKit 3, Svelte 5).
- `08-bakery` — Crumb & Co., hand-drawn pastel bakery with a chalkboard and allergen filters (Tailwind 4, Alpine.js).
- `09-esports-club` — NOVA E.C., esports club as a matchday programme with a 3D crest (React, R3F).
- `10-yoga-wellness` — Hold Studio, 1960s exercise booklet with morphing pose diagrams (Astro 7, Tailwind 4).
- `11-online-course` — SQL in 30 Evenings, squared exercise book graded in red pen (Vue 3).
- `12-finance-app` — Tally, money app as an accountant's ledger with a savings calculator (React, Tailwind 4, Recharts).
- `13-fashion-lookbook` — OSTEN, lookbook as 35mm contact sheets with a loupe (Next.js 16).
- `15-eco-nonprofit` — Second Growth, field-survey reforestation site with a tree-ring chart (Astro 7).
- `16-oss-docs` — Ferry, library docs as a 1980s reference manual with thumb-index tabs (Astro 7 + MDX).
- `17-podcast` — Long Wave, podcast as a Braun-era radio with a tuning dial (SvelteKit 3).
- `18-space-museum` — Kepler Hall, planetarium as a star atlas with a 3D celestial sphere (Three.js).
- `19-barbershop` — Sharp & Sons, wood-type broadside with a woodcut before/after slider (Tailwind 4, Alpine.js).
- `20-ai-startup` — Tern, AI startup typeset as an arXiv paper with a token-confidence figure (Next.js 16).
- `21-tech-conference` — Gate 27, conference as airport wayfinding with a split-flap board (React, Vite).
- `22-interior-studio` — Atelier Hira, material sample board that re-dresses a room (Nuxt 4).
- `23-blog-newsletter` — Marginalia, newsletter as a pocket paperback with sidenotes (Astro 7 + MDX).
- `24-pixel-game` — LAMPLIGHTER, cartridge box, manual and a playable canvas game (vanilla JS).
- Catalog (`templates.json`), docs generator, GitHub Pages gallery and deploy workflow.
