# Security Policy

The templates are static front-end code, but dependencies and copy-paste snippets still matter.

- Report vulnerabilities **privately** through [GitHub Security Advisories](https://github.com/unicorn-rm/vibe-templates/security/advisories/new). Please don't open public issues for them.
- Expect a first reply within 7 days.
- Dependency updates are monitored by Dependabot.
